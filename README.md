# Todo App

تطبيق قائمة مهام بسيط بـ HTML و CSS و JavaScript، اتعمل للتمرين على Git و GitHub.

## المميزات
- إضافة مهمة
- الضغط على المهمة لتعليمها كمنتهية
- حذف مهمة
- الحفظ تلقائيًا في `localStorage`

## التشغيل
افتح ملف `index.html` في المتصفح.

## أفكار للتمرين على Git (كل فكرة في branch لوحدها)
1. `feature/dark-mode` ← إضافة وضع ليلي
2. `feature/edit-todo` ← تعديل نص المهمة
3. `feature/filters` ← فلاتر (الكل / المنتهي / المتبقي)
4. `fix/empty-input` ← تحسين التعامل مع الإدخال الفاضي
5. `docs/readme` ← تحسين الـ README
